# 「あの塗料、持っていたっけ？」をなくす。模型塗料の在庫管理アプリ「Colorack」を作りました

![Colorackの紹介ヘッダー。模型塗料の収納ボックス、スマートフォン、色見本](https://sgwkzy.github.io/colorack/assets/note/colorack-note-header.png)

模型店で気になる色を見つけたとき、「これ、家にあったかな？」と迷ったことはありませんか。

塗料が増えるほど、色名や品番だけで手持ちを把握するのは難しくなります。保管場所も複数になると、探す時間まで増えてしまう。そこで、手持ちの模型塗料をスマートフォンでさっと確認できる在庫管理アプリ **Colorack** を作りました。

**ColorackはApp Store・Google Playで無料配信中です。**

→ [ColorackをApp Storeで入手する](https://apps.apple.com/app/colorack/id6789651166)

→ [ColorackをGoogle Playで入手する](https://play.google.com/store/apps/details?id=com.sugawalabo.colorack)

## Colorackでできること

### 手持ちの塗料を、保管場所ごとに管理

塗料を「保管箱」に分けて登録できます。引き出し、工具箱、作業机の下など、実際の置き場所に合わせておけば、必要な色がどこにあるかをすぐ確認できます。

塗料ごとに「在庫あり」「使用中」「使用済」を記録できるので、買い足すべき色も見つけやすくなります。

![Colorackの画面。保管箱の中にある模型塗料を一覧で確認できる](https://sgwkzy.github.io/colorack/assets/screenshots/box-ja.png)

### カタログから、品番を探してそのまま登録

Mr.カラー、ガイアノーツ、タミヤ、ファレホなど、主要ブランドの塗料カタログを収録。品番や色名を手入力しなくても、カタログから選ぶだけで在庫に追加できます。

![塗料カタログからブランドを選ぶColorackの画面](https://sgwkzy.github.io/colorack/assets/screenshots/catalog-ja.png)

### 「この色に近い塗料」を探せる

作例や資料を見て「この色に近い手持ち塗料はある？」と思ったときのために、色差（ΔE）をもとにした近似色検索を用意しました。

色を指定してカタログから近い塗料を探せるほか、カメラで撮影した色からHEX値を取得して検索につなげることもできます。調色の出発点を探したいときにも便利です。

![近似色を検索するColorackの画面](https://sgwkzy.github.io/colorack/assets/screenshots/color-search-ja.png)

### お気に入りと買い物リストも一緒に

気になる色はお気に入りへ。次に買う塗料は買い物リストへ。塗料を探す・持っているか確認する・買い足す、という作業をひとつのアプリでつなげられます。

## こんな方におすすめです

- 塗料が増えて、同じ色を買ってしまったことがある
- 複数の保管箱から目当ての塗料を探している
- 店頭やイベントで手持ちの色を確認したい
- 近い色から調色のヒントを得たい

データは端末内に保存されるため、まずは手元の数本から気軽に始められます。

## まずは「よく使う1箱」だけ登録してみてください

最初から全部の塗料を登録する必要はありません。いちばんよく使う保管箱をひとつ作り、手前にある塗料から登録するだけで十分です。

次に模型店へ行ったとき、Colorackを開いてみてください。「持っていたかな？」で迷う時間が少し減るはずです。
